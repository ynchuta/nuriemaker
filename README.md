# ぬりえメーカー

スクショや画像を貼るだけで、子ども向けの塗り絵（線画）にして A4 で印刷できるウェブアプリです。
画像の処理はすべてブラウザの中で行い、画像がインターネットに送られることはありません。

## できること（第1段階）

- 画像の読み込み：スクショの貼り付け（コピペ）、写真・画像ファイルの選択、ドラッグ＆ドロップ
- 線画化：「線の太さ」「細かさ」の 2 つのスライダーと、3歳・5歳・8歳向けのおすすめ設定
- 線を中心でなぞり直す：太い輪郭線が二重線（白抜き）にならないよう、線の中心を取り出して選んだ太さで描き直す（オン／オフ可）
- 切り抜き：塗り絵にしたい部分を四角で囲む
- 印刷：A4 の縦・横を画像に合わせて自動で選び、余白 10mm で印刷（PDF 保存も可）
- PNG 画像として保存

## 使い方（開発者向け）

```sh
npm install
npm run dev      # http://localhost:5173 で起動
npm test         # 線画化処理のテスト
npm run build    # dist/ に公開用ファイルを作成
```

## 公開

`main` ブランチに入ると、GitHub Actions が自動で GitHub Pages に公開します
（初回のみ、リポジトリの Settings → Pages → Source を「GitHub Actions」にする必要があります）。

## しくみ

- `src/lineart.ts` … 線画化の処理（周りより暗い細い部分＝描かれた線の抽出、色の境目、途切れた線をつなぐヒステリシス、ゴミ取り、細線化とヒゲ取り、線の太らせ）
- `src/worker.ts` … 画面が固まらないよう、線画化を Web Worker で実行
- `src/main.ts` … 画面の操作（貼り付け、切り抜き、印刷、保存）
